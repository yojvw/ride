# 给本地执行者 / DeepSeek

这是一份新增文件补丁，不要覆盖清洗数据、原io.py、原tests、旧results或原run.py。

1. 把补丁内部文件合并到原run.py同级目录，使用既有.venv。
2. 先跑原tests，再跑tests_opt。
3. 不更改默认时间切分、输入哈希、样本数和筛选门槛，先跑tune。
4. 审查baseline_reproduction.json是否逐样本复现，OPTIMIZATION_REPORT.md是否保留新方案。
5. 交回验证报告、validation_cv_metrics.csv、selection_decisions.csv和baseline_reproduction.json；不要擅自finalize。
6. 若模型不提升或基线无法复现，保留失败结果如实报告，不删校验、不换测试窗口、不改目标值。
7. 后续若经明确同意执行finalize，必须注明旧测试已被研究过；结果为探索性复核，不能称全新盲测。

可选的纯虚构环境演示：

```powershell
.venv\Scripts\python.exe tools_opt\make_synthetic.py --destination opt_demo
.venv\Scripts\python.exe optimize_bike.py tune --config opt_demo\protocol.json
```

虚构演示用12/20次迭代缩短验证耗时，实际候选用原配置80次及160次。演示仅检查程序工作机制，不验证真实数据收益。
