# 算法与实验设计说明

## 资料依据

交接报告称：238,699条有效骑行，选20站；旧模型验证MAE为借出1.1648、归还1.1947，旧测试MAE为1.4685、1.4801。其17点借出偏差为-1.56，测试需求水平高于训练。以上都是上传报告记载，非本轮重算。

本插件保留这些基线，不将模型复杂度增加等同于提升。不按旧测试的单个小时误差直接加固定偏置；这会使用已知测试情况定制模型。采用可以仅用历史特征描述的近期水平、周期与损失候选，再在验证/CV检验。

## 特征

对站点s、预测小时t，历史x取t之前的观测：

- EWM24/EWM72：对x先shift(1)，再计算指数加权均值；更近期的记录权重大。
- mean168：x[t-168:t]均值，不包含t，不需要额外的336小时窗口。
- same_hour_mean_7d：同站同钟点序列先shift(1)，最多取此前7个日样本。
- recent_ratio=(mean3+1)/(mean24+1)，避免除零。
- weekday_hour=weekday*24+hour；仅预先已知的日历信息。
- zero_fraction24：过去24小时中实际0的比例；缺失不算0。

原完整小时网格不能有缺行；无覆盖小时保留NaN。先shift再按站点滚动，不把多个站点连在一起roll。新特征有缺失时交给HGB处理，所有候选仍使用原full特征和目标完整的相同样本键。

## 预测目标与损失

Poisson模型近似学习条件均值，适合非负计数期望；absolute_error对齐MAE，近似学习条件中位数。两者优化目标不同，不能仅用某一个指标认定另一个“不合理”。固定融合是候选，不在验证或测试上任意搜索权重。

本轮没有证实零膨胀、没有拟合hurdle、没有把预测值离散化。报告中的零比例可能来自低均值Poisson、异质性或其他原因；需要适当诊断后才能引入更复杂计数分布。

## 模型选择

候选集合和默认参数预先固定。每折只用该折起点之前的可用样本训练。默认关闭HGB内部随机验证早停；不把随机validation_fraction伪装成时间验证。增加迭代次数采用固定候选，不宣称已经完成最佳时序早停。

选择需同时满足验证MAE改善、描述性配对区间上界<0、CV不过度恶化、峰值MAE与欠预测率不恶化。找不到符合条件的候选则保留hgb_full。这是保守工程规则，不是严格的模型选择后统计检验。

## 日块bootstrap

严格对齐station_id,time,actual，按自然日聚合候选绝对误差减基线绝对误差。对同一批日块有放回重采样，按各日样本量计算汇总MAE差，给出2.5%与97.5%分位。

它保留一天内部站点和小时相关性，但忽略跨日相关性，且6/7个日块很少。多候选筛选后区间可能乐观，不能仅凭不跨0宣称普适胜出。脚本并非未上传的原scripts/block_bootstrap.py，未证明两者逐位一致；本实现已用常数差值、样本错配和随机复现测试。

## 冻结与预算

LOCK保存：输入SHA256、原io/panel/forecast代码摘要、新优化模块摘要、依赖版本、原配置、候选参数、所选模型及特征集合。finalize拒绝变化。SHA校验防误操作，不是防恶意篡改的安全系统。

台账每个阶段追加状态。预算用独占文件锁和原子替换；一次finalize预留即计数，即使失败也不返还。预算只能覆盖本工具行为，无法追踪另一个脚本或人为删除文件。无需也不应绕过它来反复评分。

## 预测区间

最终阶段可给基线与锁定方案训练辅助5%/95%分位数模型。融合方案的区间由固定adaptive_poisson特征与结构的辅助分位数模型生成，不称为混合分布精确区间。交叉时排序，实测覆盖、宽度和pinball loss同时输出。未做conformal，也没有时间序列覆盖保证。

## 输出与后续

新指标保留MAE、RMSE、偏差、站点宏平均、高峰指标，并新增需求段误差、Poisson deviance（预测下界1e-9仅用于指标计算，不篡改保存预测）、配对差值。旧结果文件保持只读。

预测调度接口尚未接入本优化输出：中位数预测用于MAE评价与均值预测用于资源计划不是同一任务。后续若优化调度，应另设场景与目标，不能把MAE下降当成收益已证实。
