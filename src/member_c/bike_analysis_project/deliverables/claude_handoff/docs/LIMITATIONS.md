# 局限说明

以下限制会直接影响结论的可推广性，报告中必须同时引用。

## L1 站点覆盖是假设而非证实

coverage.csv 的 985 段区间全部为 assumed，没有运营日志或站点状态源。站点中途开关会在边界处失真。

## L2 站外端点不计入站点流量

15.6% 的骑行没有起点站、16.6% 没有终点站（几乎都是电动车自由停放）。站点借还只是“有站点记录”的部分。

## L3 只有单月数据

2024-01 一个月无法证明季节性、年度规律或其他城市可迁移；所有结论限定在该月与 761 个站点。

## L4 验证期只有 6 天、测试期只有 7 天

验证 2,880 行/目标、测试 3,360 行/目标；1% 级别的 MAE 差异在日块 bootstrap 下无法判定。

## L5 测试期已经被查看过

测试集结果已用于诊断与报告；任何后续在测试期上的比较都只是探索性复核，不是独立盲测。

## L6 候选模型没有测试成绩

v0.2.0 与 v0.2.1 的候选只有验证集与滚动 CV 成绩；本包不生成、不推测其测试成绩。

## L7 没有库存、容量与成本数据

stations.csv 只有坐标；调度建议只能是条件性优先级，不能换算成缺车量、调度车次或经济收益。

## L8 坐标为估计值

站点坐标来自入桩端点中位数；无站点端点的坐标只有约 1 km 精度，未用于站点定位。
